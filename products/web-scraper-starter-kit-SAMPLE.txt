READ ME (from the kit)
---
Headless-browser scraping foundation: render JS pages, normalize to
schema-drift-proof JSONL, land in DuckDB/Postgres. Verified end-to-end demo
included (Hacker News -> 30 records -> DuckDB).

Quickstart:
  pip install -r requirements.txt
  python -m playwright install chromium
  python src/scraper.py https://news.ycombinator.com/ | python src/normalize.py | python src/load_duckdb.py
